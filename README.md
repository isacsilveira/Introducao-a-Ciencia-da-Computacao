# Introdução à Ciência da Computação

Repositório contendo atividades, exercícios e projetos desenvolvidos durante a disciplina **Introdução à Ciência da Computação** da Universidade Federal de Alfenas (UNIFAL-MG).

## 📚 Sobre a disciplina

A disciplina tem como objetivo introduzir os principais conceitos da Ciência da Computação, desenvolvendo o raciocínio lógico e a resolução de problemas por meio da programação.

Ao longo da disciplina foram abordados conceitos como:

- Estruturas de controle
- Algoritmos
- Organização de programas
- Manipulação de arquivos
- Shell Script
- Automação de tarefas
- Ambiente Linux
- Boas práticas de programação

## 📁 Estrutura do repositório

O repositório está organizado em atividades e projetos desenvolvidos durante a disciplina.

```
.
├── atividade_01/
├── atividade_02/
├── projeto/
└── ...
```

## 🛠 Tecnologias utilizadas

- Shell Script (Bash)
- Linux
- Git
- GitHub

## 🎯 Objetivo

Este repositório tem como finalidade armazenar os códigos produzidos durante a disciplina, servindo como histórico de aprendizado e evolução acadêmica.
